# CAD-002 — Editable radial profile authoring

**Status:** experimental review candidate. Builds on [merged CAD-001](CAD_001.md) and the existing Visual Editor / Asset Foundry. Does not alter the historical roadmap, existing scene schema, graphics renderer, physics or frozen evidence.

**Reviewed main:** `25afa4a9d970cdc17fb600df3459478e8c078b91`, the exact merge of [PR #141](https://github.com/QSOLKCB/VANILLAJS/pull/141).

## What is now implemented

- **Editable radial sketches** using `cadProfileDraft`, `cadProfilePreset`, `cadProfileMove`, `cadProfileInsert`, `cadProfileRemove` and `cadProfileSegments` within the existing pure [CAD geometry module](../modules/cad-geometry/index.js).
- A native Canvas2D side-elevation profile workshop integrated with the [Visual Editor](../demos/editor/index.html). Gold ring handles can be selected and dragged to change radius or elevation. Numeric dimension inputs author the same values. Mesh triangulation is recomputed only from accepted immutable profile data; the workspace itself never changes physics or renderer authority.
- **Dimension snapping** to free, 0.025, 0.05, 0.1 or 0.25 metres. An edit that crosses an adjacent ring, exceeds the 5 m radius / 10 m height limits, introduces nonfinite coordinates or produces invalid topology is rejected **without changing the accepted sketch**.
- **Preview-only pan and zoom** with separate `cadProfileScreen` and `cadProfileUnproject` helpers. These change Canvas2D pixels only; the active WebGL scene, physics, target/game state, export and edited geometry do not change until an explicit *Generate CAD profile variant* action.
- **Recovery of editable profiles from saved CAD-001 and CAD-002 OBJ meshes** with `cadProfileRecover`: reconstruct a bounded ring profile from the existing, validated, immutable mesh triangles. It does not trust an arbitrary source filename: candidate geometry must match a re-triangulated native CAD mesh within the 6-decimal OBJ quantisation boundary.
- **Immutable asset revisions**: clicking *Generate CAD profile variant* creates a **new static scene entity and new SHA-256-provenanced mesh asset**. The original mesh and any other entities sharing it remain unchanged, so ordinary scene Undo/Redo works without rewriting shared asset geometry. A scene project can be saved and reopened with the existing `.vproject.json` schema; selecting a CAD mesh and clicking *Edit selected CAD mesh* reconstructs its profile.
- The editor's Asset Foundry still enforces its 32 asset / 128 entity / 256 KiB project / 1,536-vertex / 64 KiB OBJ budgets. Revisions intentionally occupy an asset slot: do not confuse this with an unbounded in-place edit or full feature-history system.

## Engine contract

`cadProfileDraft({profile,segments})` requires 2–8 dense `[radius,elevation]` pairs, strictly increasing elevations, finite positive-volume segments, up to 24 radial facets and a total height no greater than 10 metres. All arrays are snapshotted and frozen, with no ambient timer, random input, browser API or network access.

The original CAD-001 `revolveProfile` remains the **single triangulation authority**. `cadProfilePreset` reconstructs the exact legacy column/cone/urn shape dimensions and preserves exact floating-point vertex parity with `createCADPrimitive`. The new profile edit operations return fresh owned drafts. `cadProfileMesh` generates an owned native CAD-001 surface, which can pass through the exact existing `cadMeshOBJ` → `asset-foundry.addMeshAsset` → `setPlacement` and native WebGL path.

A recognition attempt must validate point dimensions, point count, segments, geometry size and the round-trip XYZ/UV stream. Reconstructed XYZ/U remain within one six-decimal quantisation step; V coordinates use a separate mathematically bounded tolerance based on maximum endpoint-height rounding divided by the profile span. This is not an unrestricted UV bypass. CAD-002 does not promise to recover arbitrary imported files, reconstructed CAD profiles from external software, a generic CAD format, arbitrary polygons, exact topology certification or legacy STL compatibility. Geometry is a *visual* mesh; gameplay collisions remain the original entities' AABB proxy.

## How to use

In Visual Editor → **Asset Foundry → CAD-002 Editable Radial Profiles**:

1. Generate a CAD-001 column/cone/urn, or choose *Use primitive as sketch*.
2. Select an existing native CAD mesh in the scene, and choose *Edit selected CAD mesh* to recover its rings—even after reopening a saved project.
3. Click a ring in the list or its gold Canvas handle, and edit its **Radius** or **Elevation** numerically or by dragging. Choose a snap step and optionally insert/remove a ring. Set radial facets if needed.
4. Use **Preview zoom / pan** to inspect the outline; those controls never change the authored mesh.
5. Press **Generate CAD profile variant** to create a new immutable mesh and scene entity, then save the full offline project. Ordinary Undo removes that new entity; Redo restores its placement.

**Important:** This produces a *new variant*, not an in-place modification to the selected original mesh. Shared meshes cannot be changed out from under existing scene objects. An asset-capacity rejection leaves the scene and existing assets unchanged.
