# Proposed v2.5.0 — The Creator Gateway

Draft release notes; this PR does not merge, tag or publish a release.

- Refreshed project landing page and roadmap, with complete historical references.
- A progressive creator path from first scene through mods, testing and export.
- Preserved root engineering policy, detailed task guide and locally validated workflow catalogue.
- Interactive Tutorial Lab linked from the Creator Hub: edit movement, run real
  Workbench physics, diagnose and repair a failure, then export an editable project.
- Games2 integration register preserving every current concept and donor, with
  separate approval gates and a configurable three-completed-game review cadence.
- Documentation audits and tutorial browser/offline regression coverage.
- Repaired source-bound browser receipt handling, with bounded deduplication and
  generated-package provenance checks. Reuse still requires protected reviewed
  main, matching source/environment and three qualifying real executions; no
  speedup is claimed before activation and measurement.

The engine remains experimental. Existing maths, physics, labs, Mod SDK and
verification facilities remain intact. Package/catalogue versions stay at their
historical 1.0.0 values. No Games2 game is implemented or promoted by this change.

The tutorial exports project data; the existing exporter packages the Workbench
box preview. Neither supplies a complete custom game or compiles arbitrary FPS
projects. See [execution evidence](CREATOR_GATEWAY_VERIFICATION.md) for actual
checks and unavailable hardware coverage.
