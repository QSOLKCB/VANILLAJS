# Draft — VANILLAJS v2.4.0: The Demoscene Foundry 👽🎵

For owner review. This implementation does not publish a release or move a tag.

**From blocks to worlds.** THE MACHINE REMEMBERS is an original sixty-second
realtime audiovisual production: cold boot, assembling machinery, geometric
tunnels, an alien cathedral and a final transmission that resolves to black.

- **Sample-indexed direction:** 48 kHz, 2,880,000 samples, 3,000 nominal frames,
  direct seeking and camera/effect reconstruction from absolute sample time.
- **An original complete soundtrack:** four integer synth voices, eight distinct
  phrases, actual note-driven graphics and full PCM16 WAV/score/identity export.
- **Demoscene / Visual FX in the Workbench:** capture cubes, local meshes and
  instantiated prefabs; author effects, transform/camera keys, typography and
  musical variations; preview and round-trip validated compositions.
- **Reusable engine pieces:** experimental demo-timeline, demo-scene and mod-demo
  modules, retained bounded geometry and an opt-in intro-to-menu example.
- **Portable world generation:** deterministic Node CLI output with native runtime,
  original project/score data, source/asset receipts and honest byte-budget reports.
- **Offline continuity:** content-hashed startup, older-worker compatibility,
  failed-load recovery and a full original minute available without asset downloads.

No runtime framework, CDN, proprietary assets, accounts or monetisation. No
4K/64K competition, MOD compatibility, physical-lattice or cross-GPU pixel claim.
Games2 remains unchanged. See the implementation contract and recorded execution
evidence for tested platforms, bounds and reproducibility scope.
