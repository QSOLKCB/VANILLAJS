Sound is rendered offline to PCM16 first, then previewed with Web Audio/device playback where supported.

Why 2D first?

World positions use integer subunits. +Y is up, independent of Canvas coordinates. RTS calls the existing A* oracle; movement, samples and visual commands are separately testable.

WASD/arrows move; Space fires or jumps; Q/E steer a car; Escape or focus loss pauses. No networking, login, tracking, packages or runtime services.

Ternary array store

UTF-8 bytes are represented as six base-3 digits in a 27-column grid. Invariant snapshots, a 256-entry LUT and a bounded inverse table avoid recomputing identical data.
