Your first moving scene

Change how fast a player moves. Test a real Workbench scene, learn to spot a problem, and keep an editable project. No coding needed for this lesson.

  1. Load the Playground starter
  2. Change the speed and test movement
  3. Find and repair a zero-speed problem
  4. Download your editable project

1. Load a working scene

The orange box is the player. Its Workbench Player Controller component stores movement speed in metres per second. The preview applies that speed; reusable collision handles its box contacts.

2. Make a change

Each test restarts at the authored position and runs exactly 60 Workbench physics steps. The image shows the final position; the measured distance below is the actual result, including collisions.

Loading the lesson. If this persists, serve the complete folder over HTTP and check the browser console.

3. Diagnose a problem

Zero is valid scene data, but the creator checks warn that the player cannot move. Read the diagnostic, then apply a positive speed and test again. Edits invalidate the previous test.

4. Keep your work

This downloads first-scene.vproject.json: a v2 Workbench scene and an empty asset library. Open it with Open project in the Visual Workbench to play with WASD and Space, add platforms and save further edits.

It is data, not a standalone game. To package its playable box preview with engine files, licences and offline caching, follow Export a game. Scoring, objectives, menus and custom game rules still need game code. Keep the engine's LICENSE and NOTICE when distributing engine code.
