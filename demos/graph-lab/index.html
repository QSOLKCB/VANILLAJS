What this experiment establishes

Simple undirected graphs, at most 16 vertices. BFS uses ascending neighbor IDs; DFS uses ascending-neighbor preorder. DFS depth is tree depth, not shortest distance. Relabeling preserves the polynomial; tie-broken visit order can change.

D4 transforms rational drawing coordinates exactly before conversion to canvas pixels. Drawing transforms do not change edges or vertex IDs. The grid’s D4-induced label permutations are independently tested as graph automorphisms.

No eigensolver, physical material spectrum, sound measurement or formal source-refinement proof is implied. Rendering is an illustration. Calculations run only when controls change; there is no animation loop.
