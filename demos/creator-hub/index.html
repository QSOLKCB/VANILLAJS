From a blank idea to a playable scene

  1. Choose a starter. In the editor's Quick start panel, choose Playground, Jumping course or Trigger trail and select Load starter. Loading is one undo step.
  2. Add a piece. Choose Platform, Trigger zone or Decoration. Select it and drag the coloured arrows. Press F to frame the selection; Undo reverses an edit.
  3. Check and play. Read Scene checks. Select an issue to find its object. Try Play, move with WASD and jump with Space. Stop returns to editing.
  4. Keep the editable project. Save project includes the scene and asset library. Open project restores it. Recovery is a local backup; download a file before leaving.

Focus basics hides advanced tools while you learn. Show all tools restores the full workbench. The editor provides a box-based gameplay preview; a finished game's scoring, objectives and menus still need game code.

Build a folder you can share

From a source checkout with Node 22+, download Save project in the editor, then run:

node scripts/export-game.js /path/to/game.vproject.json --out /path/to/new-game-folder

The output includes the playable preview, required engine files, licences and verified offline caching. Use a new folder; the exporter refuses to overwrite an existing one. Keep your editable project separately.

cd /path/to/new-game-folder
python3 -m http.server 8000 --bind 127.0.0.1

Open http://127.0.0.1:8000/. Serve the complete folder over HTTP(S), including on a static host. Direct file opening cannot load these native ES modules. Offline reload becomes available after the service worker finishes its first install on HTTPS or localhost.

THE DEMOSCENE FOUNDRY

Make Your First Demoscene Intro

Turn existing Workbench geometry into an original audiovisual composition.

  1. Select a cube. Choose a visible object in the hierarchy.
  2. Choose a palette. Set a contrasting inspector colour or flat material.
  3. Add motion. Open Demoscene / Visual FX, choose rotate and Add selected object / prefab. Capture transforms at two times.
  4. Frame a camera. Enter camera XYZ and target in Camera, typography & music; set a camera key.
  5. Write a scroller. Apply your own uppercase 3D title and original message.
  6. Vary a phrase. Choose musical phrase 2 and change its arpeggio octave.
  7. Sync the effect. Choose radial, eight copies and Percussion as the cue lane.
  8. Preview. Seek to 42 seconds or Preview with sound. Use silhouette, depth, contrast and repetition deliberately.
  9. Round-trip. Export validated composition; reimport in the panel and Demoscene Lab. Save scene/assets separately.
  10. Reuse it. Evaluate the public composition API or use the optional intro-to-menu adapter in your own project.

BLOCK ARENA FOUNDRY

Build Your First Blocky FPS

Start with a working arena, author your own cover and weapons, then take the data into a separately owned game.

  1. Load an arena. Open Block Arena, choose Cobalt Courtyard or Violet Switchyard, and Load draft.
  2. Place cover and spawns. Use the map tools or X/Z fields. Keep standing space clear and spawns on supported ground.
  3. Tune two weapons. Give Needle a slower, stronger shot; give Pulse a larger magazine and controlled spread. Update each weapon draft.
  4. Set rules and pickups. Add health/ammo on the map. Advanced JSON edits bot types, difficulty, match rules and wave rosters.
  5. Validate and play. Validate & test, then Enter the arena. Test both modes, weapon switching, cover and reloads.
  6. Keep the data. Export active pack, reimport it, and verify a replay. Failed imports preserve the accepted match.
  7. Build your own game. Use the public-module example with an immutable reviewed engine snapshot. Your game owns its bots, world, UI, progression and saves.
