From a blank idea to a playable scene

  1. Choose a starter. In the editor's Quick start panel, choose Playground, Jumping course or Trigger trail and select Load starter. Loading is one undo step.
  2. Add a piece. Choose Platform, Trigger zone or Decoration. Select it and drag the coloured arrows. Press F to frame the selection; Undo reverses an edit.
  3. Check and play. Read Scene checks. Select an issue to find its object. Try Play, move with WASD and jump with Space. Stop returns to editing.
  4. Keep the editable project. Save project includes the scene and asset library. Open project restores it. Recovery is a local backup; download a file before leaving.

Focus basics hides advanced tools while you learn. Show all tools restores the full workbench. The editor provides a box-based gameplay preview; a finished game's scoring, objectives and menus still need game code.

Build a folder you can share

From a source checkout with Node 22+, download Save project in the editor, then run:

node scripts/export-game.js /path/to/game.vproject.json --out /path/to/new-game-folder

The output includes the playable preview, required engine files, licences and verified offline caching. Use a new folder; the exporter refuses to overwrite an existing one. Keep your editable project separately.

cd /path/to/new-game-folder
python3 -m http.server 8000 --bind 127.0.0.1

Open http://127.0.0.1:8000/. Serve the complete folder over HTTP(S), including on a static host. Direct file opening cannot load these native ES modules. Offline reload becomes available after the service worker finishes its first install on HTTPS or localhost.
